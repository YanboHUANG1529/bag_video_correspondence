# 完整探索计划

制定日期：2026-10-18。下列时间和阈值是探索排期与起始目标，尚无算法评估结果。项目状态记录在 `../ccfa.yaml`。

## 1. 目标与交付

输入一段袋子操作视频、可用的深度／标定，以及一个数字袋子资产，输出抓取区域在资产材料表面上的位置。结果包含 `part_id + source_mesh_sha256 + face_id + barycentric + surface_side + confidence`，并保留遮挡与多解。

分两个问题推进：

1. **同实例材料对应**：现有 case00 与 bag2，根据仓库较新的来源审计属于同一实物的测量资产。验证可见袋口与把手附近的局部对应及跨帧稳定性。
2. **跨实例功能对应**：将示范中的“某片袋壁、某段袋口／把手”迁移到 bag1/3 或新袋子；几何不同的实例没有天然唯一的逐点材料真值，需定义共享语义坐标与评估标注。

第一轮最终交付：对应颜色／连线可视化、独立标注上的误差、错误袋壁率、遮挡时的置信度和拒答，以及可供现有抓取系统读取的材料锚点 JSON。机器人闭环列在后续阶段。

## 4. 每阶段的实际工作顺序

### P1：先得到可以相信的对照

1. 查看预览和 native RGB；复核 active 15/30/34/50/90，不把 user-extracted 或 source 索引直接当 active。
2. 在 Blender 中查看 bag2。标清可见侧袋壁、对侧袋壁、袋口局部链、把手连接点和桥面。bag2 边界不是简单环，先建立局部可用链。
3. 选择约 8 个结构锚点用于初始化；另外补约 8–12 个未参与拟合的评估点／区域。数量是起点，不能以共线点数量替代约束质量。
4. 若独立评估点在实拍中无法精确定位，用区域或位置区间标注；需要毫米级真实材料真值时，补采带临时标记或多视角的序列。
5. 补齐缺失手掩码或逐帧确认该手不可见。先处理算法实际使用的帧，后续再扩到全序列。

### P2：建立可比较的三条基线

- **B0：图像袋口端点比例**：复现旧探索的思路，保留端点、袋壁选择与不确定度。只作为启发式基线。
- **B1：语义局部材料坐标**：指定袋壁和边界方向，通过关键点约束构建边带坐标。检验结构约束能否减少跨壁错误。
- **B2：关键点约束的非刚性模板配准**：粗刚体初始化后，仅用可见表面数据项与材料图正则优化模板。检验其是否减少局部几何误差。

共同使用同一组初始化观测、同一评估点和相同可见性掩码。未实现的比较方法保持 `planned`。不要将自定义简化配准命名为完整 UniGarmentManip／GAM 复现。

### P3：把时间连续性加入对应

先人工点选材料特征并用视频跟踪器传播，再让跟踪轨迹约束模板；对照“每帧独立配准”和“时序配准”。选一种跟踪器先跑通。新增检测不应直接替换已固定的材料身份；遮挡期间使用预测及不确定度，重现时再验证。

### P4：何时进入学习

当局部图坐标和几何基线已经给出可信参考，而且多实例数据可用时进入。仿真通过固定材料 ID 提供形变前后的对应；不同资产之间先人工建立标准部件和坐标。先试局部描述子／局部坐标预测，再决定是否需要完整网格重建。

建议首批新增 3–5 只实物袋子、每只至少 3 种初态和 2 次独立录制，形成 18–30 段探索数据。该规模用于判断可行性；是否足够训练和泛化由学习曲线决定。

## 5. 评估与最小实验包

| 问题 | 比较 | 指标与条件 |
|---|---|---|
| 是否落在正确材料区 | B0/B1/B2 | 部件准确率、错误袋壁率、错误内外侧率；未知标签不进入该项分母 |
| 可见对应是否准确 | 三基线 | 独立点上的 PCK，起始阈值为原生图像对角线的 1%；另报告像素误差分布 |
| 材料位置是否准确 | 人工材料标注／仿真真值 | 参考材料表面的测地误差及 5/10/20 mm 阈值成功率；无独立真实表面真值时实拍该项写 N/A |
| 结构约束是否有用 | B2 去掉部件限制 | 错误袋壁率与测地误差，其他输入不变 |
| 时序约束是否有用 | 独立帧 vs 时序 | 可见材料对应误差、跨壁跳变次数、遮挡重现后的恢复；跟踪特征需是同一材料点 |
| 置信度是否有用 | 按置信度阈值扫描 | 保留比例与保留样本错误率；单列拒答率，避免靠全部拒答获得低错误率 |
| 跨袋是否成立 | 留出袋子／录制 | 按袋子汇总的区域准确率与可用材料误差；不随机拆同一视频相邻帧冒充泛化 |
| 是否帮助抓取 | 人工区域 vs 预测区域 | 同物理初态、同候选预算下的区域正确性、碰撞可行性、接触保持与滑移 |

探索通过的起始目标：审核样本中无跨袋壁／跨材料侧错误，可见点 PCK 达到 90%，有可靠材料真值时抓取邻域中位测地误差不超过 10 mm。它们是拟定工程目标，需按指腹尺寸、标注分辨率和深度误差重新确定，不作为已有性能。

结果按完整录制和实物袋子汇总。单个 case00 只能做调试与局部可行性验证。后续学习使用至少 3 个随机种子，并按袋子或录制汇总不确定性；不要把同一视频中大量相邻点当成独立样本。

## 6. 需要准备的资源

- 人工：了解袋子结构的人完成资产部件与关键点复核；首轮先做一天标注与可视化，再估算余量。
- CPU 环境：Python 3.10/3.11、NumPy、Pillow、OpenCV。当前初始化在已有 Python 3.9 环境运行；完整版本见准备报告。
- 几何基线：按需安装 SciPy、Trimesh、rtree。Blender 可用于查看和标注资产。
- 视频跟踪：一张 CUDA GPU 可加快推理，显存和片长按选定模型实测。原仓库历史记录中的 RTX 3060 仅为参考，不代表当前 GPU 已验证。
- 学习扩展：建议 WSL/Linux 独立环境，按官方项目匹配 PyTorch/CUDA；训练成本先用小样本测量，不预先承诺单卡可完成全部实验。
- 磁盘：当前复制约 98 MiB；恢复 RGB、示例云另占空间。多实例渲染与权重容量按下载／生成前的实际清单估算。
